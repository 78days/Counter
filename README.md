# Fancy Counter

A simple React app that displays a stylish counter card with increment, decrement, and reset controls.

## Features

- Increment and decrement actions using reusable React components
- Maximum count lock at 5
- Reset button to restore the counter to zero
- Keyboard support with the spacebar
- Responsive, modern card-based UI built with CSS

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

## Project Overview

This project demonstrates a simple counter built with React hooks and props. It is designed as a small UI exercise with a polished visual style and interactive controls.
